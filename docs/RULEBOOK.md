# BombCat 规则书

## 对局与目标

你与 AI 进行1v1对战。抽到炸弹猫且无法拆除的一方立即出局，对手获胜。

## 牌组与开局

牌组共34张，构成固定如下：

| 卡牌 | 数量 | 效果 |
|---|---:|---|
| 炸弹猫 | 4 | 抽到时立即结算炸弹。 |
| 拆除 | 4 | 抽到炸弹时自动消耗一张，并将炸弹秘密放回牌堆。 |
| 拒绝 | 3 | 让对手下一张功能牌失效。 |
| 攻击 | 4 | 立即转交行动权，对手承担你当前剩余行动数加一。 |
| 自我攻击 | 3 | 自己的剩余行动数加二，继续行动。 |
| 跳过 | 3 | 结束当前一次行动，不抽牌。 |
| 超级跳过 | 2 | 结束自己的全部剩余行动，不抽牌。 |
| 洗牌 | 2 | 随机重洗牌堆，双方原有的位置记忆失效。 |
| 预见未来3 | 1 | 秘密查看顶部3张牌。 |
| 预见未来5 | 1 | 秘密查看顶部5张牌。 |
| 改变未来3 | 2 | 秘密查看并重排顶部3张牌。 |
| 改变未来5 | 1 | 秘密查看并重排顶部5张牌。 |
| 抽底 | 2 | 从底部抽一张牌，结束当前一次行动。 |
| 顶底互换 | 2 | 交换顶部和底部的牌。 |

双方各获得6张手牌，其中至少一张为拆除。保证的拆除直接从上述牌组中发出，不额外生成卡牌。开局不发炸弹，发牌后重洗剩余22张牌堆，由玩家先行动。

## 行动与回合

每次获得行动权时，通常需要完成一次行动。在自己的行动中，可以先连续打出功能牌；普通抽牌从顶部取一张牌，并结束当前一次行动。

- 若还有剩余行动，仍由同一方继续。
- 若已完成全部行动，转交对手，对手从一次行动开始。
- 攻击、自我攻击、跳过和超级跳过会按卡牌效果改变这一流程。
- 每张牌依次完整结算后，才能继续操作。

例如当前剩余3次行动：打出跳过后还剩2次；打出超级跳过则直接轮到对手；打出攻击则让对手连续行动4次。

手牌上限为9张。满牌时不能直接抽牌，必须先出牌。功能牌在效果结算前离开手牌并进入弃牌堆，因此满牌时可以打出抽底，再抽入一张牌。

## 炸弹与拆除

抽到炸弹猫时，立即检查是否有拆除：

1. 有拆除：自动消耗一张拆除，将炸弹放回顶部、底部或中间的任意合法位置。
2. 完成放回后，自己的全部剩余行动结束，轮到对手进行一次行动。
3. 没有拆除：立即出局，对局结束。

炸弹不进入手牌；炸弹猫和拆除都不能主动作为功能牌打出。放回位置仅放置者知道，界面位置编号从顶部开始、从1计数。

## 拒绝

拒绝在自己的行动中打出，给对手施加一次待生效状态：

- 对手下一张功能牌仍被消耗并进入弃牌堆，但效果取消，随后清除拒绝状态。
- 普通抽牌与自动拆除不触发或清除这个状态。
- 同一目标已有自己的拒绝效果时，不能再次叠加。
- 被拒绝的一方仍可出牌；这张牌只用于消耗待生效的拒绝状态，不产生其他效果。

## 查看、重排与公开信息

预见未来和改变未来只处理顶部指定数量的牌；不足3张或5张时，处理全部剩余牌。查看和重排本身不结束当前行动。取消重排时保持原顺序。

双方知道牌堆张数、弃牌、行动次数及对手手牌数量。手牌内容、查看结果、最终重排顺序和炸弹放回位置属于私有信息。已知牌被抽走、交换或洗牌后，相应记忆随之更新。

使用抽底仍需照常结算炸弹；顶底互换在不足两张牌时没有实际效果。正常对局中炸弹反复放回牌堆，无法拆除时对局立即结束。
